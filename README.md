# 墨阅 MoYue · 本地电子书阅读器

一个跑在自己电脑上的电子书阅读器：**直接读取本地文件，不复制、不上传、不联网**。
支持 EPUB / PDF / MOBI / AZW / AZW3 / PRC / DOC / DOCX / RTF / ODT / TXT / MD / HTML / FB2。

- 书架：自动扫描文件夹、封面（无封面自动生成）、搜索、排序、格式筛选、继续阅读、拖拽导入
- 文件夹：新建 / 重命名 / 删除书架文件夹，右键书籍「移动到文件夹」；支持按格式、阅读状态、添加月份自动分类，以及 DSH 模型驱动的「AI 智能分类」
- 阅读器：分页/滚动、目录、书签、全文搜索、进度记忆、三套主题、全屏、快捷键；两侧常显翻页按钮；支持自动翻页（间隔 3–120 秒可调）
- AI 章节导读：自动识别当前章节，生成摘要、导读、结构化分析（核心论点/关键要点/论证脉络/概念解释）、思考问题与关键词；支持切章自动生成、按章节缓存、一键复制（需要 DSH「墨阅」插件提供模型通道）
- 排版：字体（宋体/黑体/楷体/系统）、字号 12–40、行距 1.2–3.0、字间距、段间距、版心宽度，全部即时生效并保存
- PDF：页面缩放、适应宽度、目录大纲、进度记忆、夜间滤镜、左右翻页按钮与自动翻页
- 格式转换在本机完成：Kindle 格式经 KindleUnpack 转 EPUB，Word/RTF/ODT 经 mammoth/LibreOffice，TXT/HTML/FB2 自动生成 EPUB

## 阅读快捷键

| 按键 | 作用 |
|---|---|
| ← / →、PageUp / PageDown、空格 | 上一页 / 下一页 |
| A | 开关自动翻页 |
| I | 打开 / 关闭 AI 章节导读 |
| T | 目录；S 设置；F 全屏；B 书签；/ 搜索 |
| + / − | 调大 / 调小字号 |

字体、字号、行距、字间距、段间距只对 EPUB 等流式电子书生效；PDF 保持固定版式。自动翻页的间隔与开关在「阅读设置 → 自动翻页」中调整，手动翻页会重新计时。

## 文件夹与自动分类

书库顶部是文件夹栏：

- **新建文件夹**：给书架建立分类（如「销售管理」「待读」）
- **移动书籍**：在书籍上右键 →「移动到文件夹…」；也可以移动到「未分类」
- **管理**：重命名 / 删除文件夹（删除只移回「未分类」，不会删除磁盘文件）
- **自动分类**：按规则一键整理
  - 按格式：EPUB / PDF / Kindle / Word / 文本网页
  - 按阅读状态：未读 / 在读 / 已读完
  - 按添加月份：如「2026年11月」
  - **AI 智能分类**：把书名/作者发给当前 DSH 模型，按主题（销售、管理、思维、沟通…）自动分组；需要 DSH「墨阅」插件提供模型通道

自动分类创建的文件夹会标记为自动文件夹，整理后自动清理空文件夹；手动创建的文件夹不会被删除。

## 封面

- 有封面的电子书直接显示（EPUB 内嵌封面、PDF 首页渲染等）
- 没有封面时自动生成一张排版封面：根据书名、作者、格式生成稳定配色与版式，600×900 SVG，风格与书架一致
- 封面按书 id 缓存在 `data/covers`；真实封面或自动封面都通过 `/api/books/<id>/cover` 提供

## AI 章节导读

阅读时点顶栏的 ✨ 按钮（或按 `I`）打开右侧 AI 导读面板：自动识别当前章节（PDF 为当前页），生成

- **摘要**：150–250 字概括本章内容
- **导读**：本章在全书中的位置、作者意图、阅读时该带着的问题
- **结构化分析**：核心论点、关键要点、论证脉络、概念解释
- **思考问题**：4–6 个由浅入深的迁移思考题
- **关键词**：便于回顾与串联

打开面板会为当前章节自动生成一次；勾选「切章自动生成」后，翻到下一章节会自动生成未缓存的导读。结果按「书 + 章节」缓存在本地，重复阅读同一章不再消耗模型额度，可一键复制成文字。

> AI 能力由 DSH「墨阅」插件（[wisdomzking/moyue-dsh-plugin](https://github.com/wisdomzking/moyue-dsh-plugin)）通过当前 DSH 默认模型提供（本机代理 `127.0.0.1:7797`）。因此：阅读器需要在 DSH 里运行，或本机有插件代理时该功能才可用；章节文本会发送给模型服务商，请注意书籍内容的隐私与模型额度消耗。阅读器本体不依赖 AI，可独立使用。

## 快速开始

1. 双击 **`启动墨阅.cmd`**（会自动启动本地服务并打开阅读器窗口）。
2. 点右上角 **添加文件夹**，选择你存放电子书的目录；也可以把单个文件拖进窗口。
3. 点击书封开始阅读，进度会自动保存。

打开指定文件（也支持把文件拖到 `打开书.cmd` 上）：

```bat
打开书.cmd "D:\Books\三体.epub"
```

停止后台服务：双击 `停止墨阅.cmd`。默认地址 <http://127.0.0.1:7788>。

## 格式支持

| 格式 | 说明 |
|---|---|
| EPUB | 原生渲染（epub.js）：分页、目录、CFI 进度、主题 |
| PDF | 原生渲染（pdf.js）：缩放、大纲、进度、夜间滤镜 |
| MOBI / AZW / AZW3 / PRC | 首次打开时用 KindleUnpack 转成 EPUB 并缓存，之后秒开 |
| DOCX | mammoth 解析正文与图片，自动按标题切章 |
| DOC / RTF / ODT | LibreOffice 转 DOCX 后再解析 |
| TXT / MD | 自动识别 UTF-8 / UTF-16 / GBK，按"第X章/Chapter N"切章 |
| HTML / XHTML | 提取正文重排 |
| FB2 | 解析书名/作者/章节（best-effort） |

> 转换结果缓存在 `.cache/`，源文件修改后会自动重建；转换不影响原始文件。

## 依赖说明

- 必需：Node.js 20+（本机已装）。前端库已随项目携带（`web/vendor/`），运行不需要联网。
- 可选（缺失时对应格式不可用，其它格式不受影响）：
  - Python 3.8+：Kindle 格式、PDF 封面/元数据（本机已装，含 PyMuPDF）
  - LibreOffice：DOC / RTF / ODT（本机已装）

`GET /api/health` 会报告这些能力是否可用。

## 项目结构

```
server/server.js        HTTP 服务、API、静态资源
server/lib/             书库、扫描、进度、书签、目录浏览、全文搜索
server/formats/         各格式 probe / 转 EPUB
web/                    书架与阅读器前端（原生 JS，无构建）
web/vendor/             epub.js、pdf.js（已内置）
test/                   样书与自测脚本
scripts/                启动/停止/右键菜单脚本
data/                   书库数据与日志（自动生成）
.cache/                 转换缓存（可随时删除）
```

开发模式：

```bat
node server\server.js --port 7788
```

启动器也支持命令行参数：

```bat
node scripts\launch.js --no-browser      :: 只启动服务，不开浏览器
node scripts\launch.js --open "D:\Books\三体.epub"
```

无后端调试前端：`node test\mock-api.js`（<http://127.0.0.1:7790>）。

## 常见问题

- **打开 Word/MOBI 慢？** 首次需要转换，之后读缓存；大文件可能需要几秒。
- **扫描不到书？** 支持格式见上表；文件夹嵌套最多 6 层，隐藏目录会被跳过。
- **端口被占用？** 启动脚本会检测已有服务；如仍冲突，编辑 `scripts/launch.js` 的 `PORT` 默认值。
- **数据在哪？** `data/library.json`（书库、进度、设置），删除即恢复初始状态（不会删你的书）。
- **加密/DRM 电子书？** 不支持，打开时会给出明确提示（请使用无 DRM 的版本）。
- **AZW3/KF8？** 通过 KindleUnpack 解析，绝大多数可正常阅读；极少数使用复杂 SVG/固定版式的书可能排版降级。
- **DOC 标题显示文件名？** 老式 .doc 的元数据读取有限，转换后正文正常，标题可能暂时取文件名。
- **PDF 能搜全文吗？** 当前 PDF 支持翻页/缩放/目录/进度/夜间滤镜，全文搜索仅适用于 EPUB 及转换后的其它格式。
